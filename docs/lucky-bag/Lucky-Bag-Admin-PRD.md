# 红包记录

## 一、菜单入口

活动管理 > 红包记录

## 二、筛选条件

- 发送人：支持 UID、昵称搜索；UID 精确匹配，昵称模糊匹配
- 房间 ID：精确匹配
- 红包类型：全部 / 房间红包 / 世界红包
- 红包状态：全部 / 待开启 / 可领取 / 已抢完 / 已过期
- 是否退款：全部 / 是 / 否
- 发送日期：默认最近 7 个自然日（含当天）

操作按钮：查询、重置

## 三、数据总览

页面顶部展示：

- 发送数量：符合筛选条件的红包数量，1 个红包 ID 计 1 个
- 红包发送金额（Coin）
- 平台手续费（Coin）
- 退款总金币（Coin）

数据总览仅关联以下筛选条件：

- 发送人
- 房间 ID
- 红包类型
- 发送日期

## 四、红包列表

列表字段：

- 红包 ID
- 房间 ID
- 红包类型
- 发送人
- 开启倒计时
- 发送金额（Coin）
- 平台手续费（Coin）
- 可领取总额（Coin）
- 总份数：展示红包总份数
- 领取进度：分两行展示
  - 已领取份数 / 总份数
  - 已领取金币 / 可领取总额
- 剩余金币（Coin）
- 是否退款：是 / 否
- 红包状态：待开启 / 可领取 / 已抢完 / 已过期
- 发送时间
- 操作：查看领取明细

列表默认按发送时间倒序。

## 五、领取明细

点击「查看领取明细」打开详情弹窗。

### 5.1 总览

展示：

- 红包 ID
- 发送人 UID
- 红包类型
- 是否退款
- 开启倒计时
- 发送时间
- 开启时间
- 失效时间

### 5.2 成功领取记录

记录区域顶部展示：

- 领取份数：已领取份数 / 总份数
- 领取金币：已领取金币 / 可领取总额

领取记录字段：

- 用户 UID
- 用户昵称
- 领取金额（Coin）
- 领取时间

其他要求：

- 仅展示成功领取记录
- 默认按领取时间倒序
- 无领取记录时展示空状态
