# Lucky Bag（幸运红包）— 服务端业务 PRD

> 状态：草稿（待确认，未正式发布）  
> 时间标准：UTC+5  
> 范围：房间红包、全服红包

## 一、需求说明

### 1. 功能说明
- 新增用户在房间内发送红包功能，红包发送后绑定当前 `room_id`，按照用户选择的红包金额、领取人数及开启倒计时执行。
- 红包发送及领取均不计入现有用户消费流水、财富值、主播流水、主播收益、魅力值等统计及结算。
- 本需求涉及时间统一使用 UTC+5。

### 2. 红包类型
- 红包发送后绑定当前 `room_id`。
- 分为房间红包和全服红包，两者领取规则及红包流程一致。
- 全服红包仅额外向全服用户推送红包横幅，用户点击后进入红包所在房间。

## 二、红包配置

| 配置项 | 房间红包 | 全服红包 |
| --- | --- | --- |
| 发送金额（coins） | 1,000 / 10,000 / 50,000 / 100,000 | 150,000 / 300,000 / 500,000 / 1,000,000 |
| 领取人数 | 5 / 10 / 20 / 30 / 50 | 10 / 30 / 50 / 80 / 100 |
| 开启倒计时 | Now / 1 min / 3 min / 5 min | Now / 1 min / 3 min / 5 min |
| 领取有效时长 | 10 分钟，后台统一管理 | 10 分钟，后台统一管理 |
| 平台服务费 | 5% | 5% |

- 开启倒计时选 `Now` 时，实际开启时间 = 红包发送成功时间。
- 领取有效时长不是用户可选择项。
- 实际失效时间 = 实际开启时间 + 领取有效时长。

## 三、发送红包

### 1. 发送参数
用户选择红包类型、红包金额、领取人数和开启倒计时。

### 2. 余额校验与扣款
- 服务端校验用户 coin 余额是否足够支付发送金额；通过后扣除红包发送金额。
- 红包实际可领取金额 = 红包发送金额 − 平台服务费（5%）。

### 3. 红包金额生成
- 创建红包时，一次性完成全部领取份额的随机金额生成。
- 生成份数 = 选择的领取人数。
- 所有预生成金额之和 = 实际可领取金额。
- 每份金额须 ≥ 1 coin。
- 金额随机生成的具体算法由服务端实现。

### 4. 开启及失效时间
- 实际开启时间 = 发送成功时间 + 开启倒计时。
- `Now`：实际开启时间 = 发送成功时间。
- 实际失效时间 = 实际开启时间 + 领取有效时长。

### 5. 房间状态变化
红包绑定 `room_id` 后，房主下播、直播类型切换等均不影响红包自身开启、领取及失效流程。

### 6. 红包基础信息
创建成功后记录：
- 红包发送用户 ID、`room_id`、红包类型；
- 发送金额、领取人数、实际可领取金额；
- 实际开启时间、实际失效时间；
- 已领取人数、已领取金额、退款金额等基础信息。

## 四、红包领取及状态

### 1. 领取条件
- 领取时处于房间内的成员均可参与，包括发送者本人。
- 红包开启后、失效前可发起领取。
- 每个用户对同一红包仅可成功领取一次。
- 为未来的送礼、关注等限制预留服务端领取条件校验能力。

### 2. 红包状态
| 状态 | 判定及行为 |
| --- | --- |
| 待开启 | 当前时间 < 实际开启时间；不可领取 |
| 领取中 | 实际开启时间 ≤ 当前时间 < 实际失效时间，且仍有未领取份额；可领取 |
| 已领完 | 所有预生成份额已领取；不可再领取 |
| 已失效 | 当前时间 ≥ 实际失效时间；不可再领取 |

### 3. 领取处理
1. 客户端发起领取请求，服务端校验红包状态与用户领取记录。
2. 状态为「领取中」且用户未领取过时，按成功处理顺序分配下一份预生成金额。
3. 并发领取以服务端实际处理成功的先后顺序分配，直到份额全部领完。
4. 领取成功后记录用户、金额、领取时间，并更新已领取人数及已领取金额。
5. 每次领取成功且金额 > 0 时，向当前房间推送一次公屏消息：
   > Congratulations to {领取用户昵称} for grabbing {金币数量} coin from the lucky bag!
6. 最后一份金额领取成功后，红包立即进入「已领完」状态。
7. 达到实际失效时间后，红包进入「已失效」状态。

## 五、退款

### 1. 退款规则
- 红包达到实际失效时间后，仅退还未领取的实际可领取金额。
- 已收取的 5% 平台服务费不参与退款。
- 退款金额 = 实际可领取金额 − 已领取金额。
- 红包全部被领取时退款金额为 0，不执行退款操作。
- 同一个红包仅允许退款一次。

### 2. 退款通知
- 红包失效后存在实际退款金额时，完成退款，并向红包发送方推送系统通知：
  > N coins from your Lucky bag has been refunded to your account.
- `N` 为退还的 coin 数量。
- 退款金额为 0 时不退款、不发送退款通知。

### 3. 示例
| 项目 | 金额 |
| --- | ---: |
| 发送金额 | 1,000 coin |
| 平台服务费（5%） | 50 coin |
| 实际可领取金额 | 950 coin |
| 已领取金额 | 539 coin |
| 到期退款 | 411 coin |
