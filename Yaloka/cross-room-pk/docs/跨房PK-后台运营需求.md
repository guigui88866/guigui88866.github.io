# 语聊房 PK 2.0——跨房 PK 后台运营需求

## 一、PK类型

PK类型筛选新增「跨房PK」选项。

## 二、列表展示

- PK类型：显示「跨房PK」。
- 房间ID：分别展示我方房间ID、对方房间ID。
- 参与主播：按红蓝双方展示主播昵称及个人PK值。
- 其他字段沿用现有展示规则。

## 三、PK对局详情

- PK类型：显示「跨房PK」。
- 房间ID：展示双方房间ID。
- 参与主播数据：同时展示双方参赛主播，所属队伍区分红队、蓝队。
- 助力榜：支持红队、蓝队TAB切换，分别展示双方助力榜数据。

## 四、其他

原有后台UI、列表字段及详情页面布局不变，仅增加跨房PK相关数据展示。
