# Team PK V1.0 — 运营后台需求

基于现有「主播 PK 记录」菜单扩展，不新增独立菜单。原有视频 1V1 PK、多人 PK 的展示方式保持不变，仅语音团队 PK 使用新增展示规则。

## 一、PK 记录列表调整
- **PK 类型筛选**：新增「语音团队 PK」。
- **房间 ID**：筛选项及列表新增房间 ID 字段。
  - 展示发起 PK 所在房间的 ID。
  - 1V1 PK、多人 PK 类型显示 `--`。
- **参与主播**：语音团队 PK 按红蓝队伍分组展示主播昵称及个人 PK 值。

  红队：

  主播 A（PK值：99）、主播 B（PK值：99）、主播 C（PK值：99）。

  蓝队：

  主播 D（PK值：99）、主播 E（PK值：99）、主播 F（PK值：99）。

- **PK 结果**：语音团队 PK 展示红胜、蓝胜、平局。
- **本场 MVP**：展示获胜队伍助力值最高的支持者 ID、昵称及累计助力值；平局显示 `--`。

## 二、PK 对局详情调整

### 1. PK 对局详情
- 新增房间 ID。
- 新增红队、蓝队最终团队 PK 积分。

### 2. 参与主播数据
- 新增所属队伍字段，区分红队、蓝队。
- 仅展示 PK 结算时仍在麦的主播。
- 展示主播个人 PK 积分及助力人数，数据按实际贡献统计。

### 3. MVP
- 展示本场 MVP 的用户 ID、昵称及累计助力值。
- 平局不展示 MVP，显示 `--`。

### 4. 助力榜
- 沿用现有按主播切换查看助力榜的方式。
- 不调整原有助力榜样式及交互。
