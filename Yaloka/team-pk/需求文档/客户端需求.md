# Team PK V1.0 — 客户端需求

## 一、PK 入口
- 房间工具面板新增 Team PK 入口。
- 仅房主和管理员可见，普通用户不展示。
- 点击入口，弹出【发起 PK】弹窗。

## 二、发起 PK 弹窗
- PK Time：默认选中第一项。
- PK Participants：默认选中第一项。
- Rules：点击打开【PK Rules】弹窗。
- Records：点击打开【PK Records】弹窗。
- Start PK：提交 PK 创建请求，成功后进入准备阶段。
- 8V8 未达到房间等级要求、当前已有进行中的 PK 时，展示服务端返回的错误提示。

## 三、PK 流程
发起 PK → 切换对应人数的 PK 麦位布局 → 进入准备阶段 → 点击 Start → 播放开始动画 → 正式 PK → 剩余 10 秒播放倒计时动画 → PK 结束并播放结算动画。

## 四、准备阶段
### 1. PK 条及数值
- PK 条、积分展示及动效复用现有视频 PK 逻辑。

### 2. 麦位展示
- 根据参赛人数展示对应 PK 麦位布局。
- 用户上麦后展示头像、麦序、昵称及房主标识（若有）。

### 3. 按钮交互
- Start 按钮：
  - 房主 / 管理员：显示 Start，按钮带轻微缩放动效。
  - 其他用户：显示 Waiting。
  - 点击 Start 后播放开始动画，原按钮位置切换为 `mm:ss` 倒计时。
- Rules：全员可见，点击打开规则弹窗。
- 关闭按钮：仅房主 / 管理员可见，点击直接退出 PK，无需二次确认。

## 五、正式对战阶段
### 1. 麦位展示
- 主播麦位增加个人 PK 积分框，实时更新积分。

### 2. 首杀
- 首杀倒计时、触发交互及动效复用视频 PK 逻辑。
- Team PK 首杀时间为 60 秒，积分加成按照 Team PK 规则执行。

### 3. 助力榜
- 助力前三用户的展示及更新复用视频 PK 逻辑。

### 4. 麦位操作
- 下麦、跨队换麦：弹出【更换队伍 / 下麦】确认弹窗，确认后执行操作。
- 同队换麦：无需确认，直接切换。

### 5. 关闭 PK
- 仅房主 / 管理员可操作。
- 点击关闭按钮，弹出二次确认弹窗。
- 确认后直接结束 PK 并进入结算。

## 六、结算阶段
- PK 结束后播放结算动画。
- 红胜：展示双方最终积分、红队最佳主播及红队 Top 3 支持者。
- 蓝胜：展示双方最终积分、蓝队最佳主播及蓝队 Top 3 支持者。
- 平局：展示双方最终积分、红蓝双方最佳主播及各自贡献最高的支持者。
- 点击弹窗外空白区域关闭结果弹窗，返回准备阶段，保留当前麦位及上麦用户，清空本轮积分。

## 七、PK Rules
- 点击 Rules 打开 PK Rules 弹窗。
- 规则内容由服务端返回，客户端负责展示。
- 支持多语言。

## 八、PK Records
- 展示最近 100 场 PK 记录，按 PK 发起时间倒序排列。
- 展示 PK 对战人数、红蓝双方最终积分、比赛结果及结算时主播个人积分排名。
- 仅展示结算时仍在麦的主播。
- 无记录时展示空状态：占位图 + `No data`。
- 下拉至列表底部且无更多数据时，展示：`Display up to 100 records`。

## 九、Support Rules
- 点击 Support Rules 打开助力榜规则弹窗。
- 规则内容由服务端返回，客户端负责展示。
- 支持多语言。

## 十、公屏消息
- 接收服务端推送的 PK 公屏消息，并根据消息类型、动态字段及高亮信息展示。
- 消息场景包括：PK 正式开始、触发首杀、红队获胜、蓝队获胜、平局及 MVP 通知。
- 高亮色值：`#FEDB7C`。
