Lucky Gifts 活动后台

原型

项目目的：为海外社交产品 LiveMe 的活动运营团队设计一套完整的管理后台，覆盖主播筛选、档位配置、数据总览等核心路径，降低运营人工操作成本，解决原有 Excel 手动管理效率低、易出错的问题。

项目内容：主播列表筛选与批量操作、档位阶梯配置（按流水/时长等多维度）、活动数据总览看板、奖励发放记录与对账。共 20+ 页面，覆盖运营日常配置到数据复盘的全流程。

Manager Benefits 收益管理

前端 Demo

项目目的：针对经理角色设计团队收益管理页面，展示周收益统计、额度进度、团队排行及奖励发放确认等功能模块。练手项目，独立完成前端实现并部署至 GitHub Pages，验证从设计到上线的完整链路能力。

项目内容：本周收益概览卡片、额度使用进度条、团队成员收益排行表、奖励发放确认弹窗、历史收益趋势。纯前端实现，数据通过 JSON 模拟，页面响应式适配桌面与移动端。
